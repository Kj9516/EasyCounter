# Ручная приемка EasyCounter на устройствах

Expo export и тесты на Node подтверждают сборку JavaScript и SQL-логику, но не заменяют запуск нативного приложения. Отмечайте платформы независимо и записывайте фактические результаты.

## iOS

- [ ] Открыть приложение через поддерживаемый Expo Go или development build.
- [ ] Создать проект, экран и параметр; полностью закрыть приложение и проверить восстановление данных.
- [ ] Создать кнопку и правило, нажать в режиме использования и проверить значение/историю.
- [ ] Проверить запрос ввода и его отмену; отмена не должна фиксировать предварительные изменения.
- [ ] Проверить выбор, переключатель и контейнер, затем редактирование сетки.
- [ ] Проверить VoiceOver для подписей кнопок/значений и ввод системной клавиатурой.
- **Статус:** не проверено в среде разработки.
- **Устройство / iOS / дата / результат:** —
