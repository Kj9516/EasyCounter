# Ручная приемка EasyCounter на устройствах

Expo export и тесты на Node подтверждают сборку JavaScript и SQL-логику, но не заменяют запуск нативного приложения. Отмечайте платформы независимо и записывайте фактические результаты.

## iOS

- [ ] Открыть приложение через поддерживаемый Expo Go или development build.
- [ ] Создать проект, экран и параметр; полностью закрыть приложение и проверить восстановление данных.
- [ ] Создать кнопку и правило, нажать в режиме использования и проверить значение/историю.
- [ ] Проверить запрос ввода и его отмену; отмена не должна фиксировать предварительные изменения.
- [ ] Проверить выбор, переключатель и контейнер, затем редактирование сетки.
- [ ] Проверить VoiceOver для подписей кнопок/значений и ввод системной клавиатурой.
- **Статус:** не проверено в среде разработки.
- **Устройство / iOS / дата / результат:** —

## Этап D — отдельно пройти на iOS и Android

- [ ] Создать обратный таймер, запустить, сверить изменение времени; свернуть приложение, подождать и вернуться — значение должно восстановиться.
- [ ] Настроить правило «Таймер завершён», проверить однократный запуск на нуле; повторить с разрешённым отрицательным отсчётом и убедиться, что таймер продолжает идти ниже нуля.
- [ ] Создать периодическое правило с коротким интервалом. Закрыть приложение на четыре интервала и проверить режимы восстановления «все» (четыре запуска), «один раз» (один запуск) и «пропустить» (без действия).
- [ ] Создать ежедневное и еженедельное расписания, проверить заданный часовой пояс и момент срабатывания. Зафиксировать результат перехода летнего/зимнего времени, если дата приемки позволяет.
- [ ] Экспортировать шаблон и полную копию; импортировать копию и проверить независимость параметров, правил, экранов, виджетов и связей ID.
- [ ] В полной копии проверить runtime и экспорт истории с историей и без нее.
- **Статус iOS этапа D:** не проверено.
- **Устройство / версия iOS / дата / результат:** —
- **Статус Android этапа D:** не проверено.
- **Устройство / версия Android / дата / результат:** —
