# Подключение и проверка через Expo Go

## Готовый сценарий

Ветка `device-acceptance` использует Expo SDK 57, чтобы соответствовать актуальной версии Expo Go для iPhone и Android. Проверка запускается через QR development server; устанавливать EAS development build и иметь Apple Developer Program не нужно. С сентября 2026 года Expo Go из App Store поддерживает SDK 57; для iPhone войдите в один и тот же Expo аккаунт в CLI и в Expo Go ([объявление Expo](https://expo.dev/changelog/expo-go-57-login)).

В приложении сейчас доступны проекты, экраны и настройки проекта. Это проверяет реальный React Native запуск и локальную SQLite-базу. Движок этапа B пока не подключён к визуальному редактору, поэтому его сценарии проверяются автоматическими тестами.

## Подготовка

На компьютере должны быть Node.js 22.13+ и pnpm 10+. На телефоне установите Expo Go:

- iPhone: Expo Go из App Store.
- Android: актуальный Expo Go из Google Play.

На iPhone войдите в CLI и Expo Go под одним Expo аккаунтом: Expo Go для iPhone требует совпадения аккаунта при подключении к dev server ([инструкция Expo](https://docs.expo.dev/troubleshooting/expo-go-sign-in-required/)). Пароль и токены не добавляйте в репозиторий.

## Запуск

```bash
git switch device-acceptance
pnpm install --frozen-lockfile
pnpm exec expo login
pnpm run start:device
```

Подключите компьютер и телефон к одной Wi-Fi сети. Команда запускает Expo Go target в локальной сети и показывает QR. Оставьте терминал запущенным. Отсканируйте QR штатной камерой iPhone или сканером QR в Expo Go на Android.

Expo должен быть запущен на компьютере, который подключен к той же сети, что и телефон. Запуск из удалённой среды, контейнера или виртуальной машины может показать адрес, недоступный телефону. В напечатанном Expo URL должен быть локальный адрес компьютера из той же Wi-Fi сети, обычно `192.168.x.x` или `10.x.x.x`, а не `localhost`, `127.0.0.1` или адрес удалённого контейнера.

Если iPhone сообщает об аккаунте, проверьте, что CLI и Expo Go используют один Expo аккаунт. При таймауте проверьте, что VPN выключен на компьютере и телефоне, разрешите входящие подключения Node.js/Expo в локальной сети и отключите на роутере изоляцию Wi-Fi клиентов. Повторите запуск и откройте QR камерой iPhone. Если таймаут остаётся, передайте адрес `exp://...` из терминала и строку URL из QR: по ним можно определить, рекламирует ли Expo правильный сетевой адрес.

## Проверка на каждом телефоне

1. Стартовый экран открывается без ошибки; дождитесь загрузки списка проектов.
2. Создайте проект с русским названием и описанием, откройте его.
3. Добавьте два экрана, переименуйте один, удалите другой.
4. Откройте настройки проекта, измените название/описание и сохраните.
5. Завершите Expo Go через переключатель приложений и откройте QR-проект снова. Убедитесь, что проект и экраны сохранились.
6. После первичной загрузки JS-бандла включите авиарежим, перезапустите приложение и проверьте локальные данные.
7. Создайте копию проекта, измените копию и проверьте, что оригинал не изменился.
8. Удалите тестовые проекты и проверьте, что они исчезли из списка.
9. Проверьте навигацию назад, экранную клавиатуру и поля на малом экране.
