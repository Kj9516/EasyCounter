EasyCounter — локальный нативный универсальный конструктор счетчиков для iOS/Android на React Native + Expo + TypeScript. Не подменять мобильное приложение веб-сайтом. Не вводить встроенные предметные сущности (игры, очки, деньги, игроки, здоровье).

**Why:** пользователь явно требует универсальный движок согласно ТЗ.

**How to apply:** реализовывать отдельными этапами: A — мобильная основа, навигация и локальная персистентность; B — типы, выражения, параметры, вычисляемые параметры, правила, FIFO и атомарные транзакции с тестами; C — редакторы параметров, правил, экранов и виджетов; D — таймеры, расписания, импорт/экспорт и end-to-end проверки. После каждого этапа показывать результат, тесты, ограничения и способ проверки на телефоне. Неутвержденные допущения разрешать минимально сложным безопасным вариантом и фиксировать в журнале решений.
